## NetworkManager verification

Command:

```bash
nmcli -f ipv4.method,ipv4.addresses,ipv4.gateway,ipv4.dns connection show "Wired connection 1"
```

Observed output:

```text
ipv4.method:     auto
ipv4.addresses:  10.0.0.2/24
ipv4.gateway:    10.0.0.1
ipv4.dns:        10.0.0.1
```

This confirms that the Kali connection profile uses automatic IPv4 configuration (DHCP), with the listed address, gateway, and DNS value.

## DNS note

The NetworkManager connection profile reports `10.0.0.1` as its configured DNS value. The displayed `/etc/resolv.conf` also contained `1.1.1.1`, `0.0.0.1`, and `1.1.1.2` as nameserver entries. The `0.0.0.1` entry appears unusual and has not been independently validated. DNS resolution nevertheless succeeded in the hostname ping test. The resolver file is generated by NetworkManager, so its runtime contents may differ from the connection profile.

## Summary

The Kali VM is connected to the `NatNetwork` NAT Network, receives `10.0.0.2/24` through DHCP, and uses `10.0.0.1` as its default gateway and configured DNS server. Internet connectivity by IP and hostname was verified. The gateway responded to three observed ping requests, although the four-packet test was interrupted before completion.
